# 蒸馏原料

每位博主一个目录：`feeds/sources/<博主ID>/`。原始文件只读。

```
feeds/sources/<博主ID>/
├── _index.md        # | 编号 S-01 | 标题 | 类型（视频/文章/直播） | 日期 | 链接或文件名 | 是否有逐字稿 |
├── S-01.md          # 逐字稿或文章正文
├── S-02.md
└── raw/             # 你下载好的视频或原文件（可选）
```

## 原料建议
- 数量：至少 15 条，覆盖他的主要题材；越能体现「他怎么判断、怎么取舍」越好（如复盘、选题解释、回答粉丝提问）。
- 视频需要逐字稿：平台自带字幕优先；没有字幕的，需要语音转文字工具（本机尚未安装，见 PRD FR-14 依赖）。
- 只收公开内容，仅供本地学习使用。

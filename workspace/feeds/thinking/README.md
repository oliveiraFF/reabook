# 思维投喂 · 博主蒸馏档案

每位博主一份档案：`feeds/thinking/<博主ID>.md`。它既是 idea / script 的思维投喂，也是该博主「赛博人物」模块的底子（PRD FR-14）。

## 原料
放在 `feeds/sources/<博主ID>/`，见该目录 README。档案中每条规则都必须能指回原料。

## 档案格式
```
# 蒸馏档案：<博主名>（<博主ID>）
版本：v1 · 蒸馏日期：YYYY-MM-DD · 原料数：N 条（列表见 sources/<博主ID>/_index.md）
定位一句话：他是谁、给谁做内容、凭什么被关注

## 一、判断规则（遇到选题 / 方案先看什么）
- T-<ID>-01 【规则】 —— 出处：S-03 第 2 段；S-07 00:45
- T-<ID>-02 ...

## 二、取舍原则（冲突时选什么）
- P-<ID>-01 当【X】与【Y】冲突时，选【X】，因为【…】 —— 出处：…

## 三、表达特征
- E-<ID>-01 开头：…（例句改写，不照搬原文） —— 出处：…
- E-<ID>-02 节奏 / 结构：…
- E-<ID>-03 常用句式与口头禅：…（每条引用原文不超过 15 字）
- E-<ID>-04 绝不会说 / 绝不会做：…

## 四、知识边界
- 他明确懂的领域：…
- 他从没谈过、模拟时必须说「他没聊过这个」的领域：…

## 五、验证记录
| 日期 | 测试 | 结果 | 改了哪条 |
|---|---|---|---|
```

## 规则
- 每条规则必须有出处；找不到出处的「感觉他会这样想」不得写入。
- 例外：`base.md` 是通用选题判断（不对应真实博主），没有原料出处，以「老板确认」作为依据。
- 原文引用每条不超过 15 字；其余一律用自己的话概括。
- 档案只用于学习思路与风格，产出不得冒充本人发布。
- 改档案升版本号；旧版本保留，记录在验证记录里。

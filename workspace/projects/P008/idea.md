# 创意方案 — P008

> 便携折叠颈挂风扇 · 60 秒带货短视频 · 目标「学生党」· 第一步（只出 3 个方向 + 推荐 + 待确认项，不展开、不写脚本）

## 目标
给「学生党」看，让他在 60 秒内记住这台产品【待确认：品类】的一个可用场景，并在结尾完成一个明确动作（下单 / 加购 / 收藏 / 关注——每条视频只选一个，见「待确认项」）。

## 方向 A：场景反转型——「腾不出手」的反差
- **一句话概念**：拍学生党一天里几个「又热又腾不出手」的瞬间，用「别人腾不出手、主角手是空的」做反差，把「免手持」这一形态差异（颈挂/挂脖【待确认】）变成记忆点。
- **为什么可行**：T-base-02（有冲突/反常识：风扇不一定要用手拿，前提「免手持」成立【待确认】）；T-base-01（受众具体：体育课后、拎着饭、挤公交的学生【推断】）。
- **开头钩子**：「体育课下课，别人两只手抱水壶擦汗，我两只手都在刷手机。」（具体场景切入 E-base-01；3 秒内出反差 S-01-5；「手是空的」依赖免手持/颈挂成立【待确认】）
- **风险**：核心反差依赖「免手持（颈挂/挂脖）」成立，该属性【待确认】；若只有口播、没有实拍「手是空的」画面则不可证明（T-base-04）。

## 方向 B：对比证明型——「能塞进书包的体积差」
- **一句话概念**：用「收纳前 vs 收纳后」的体积对比（折叠【待确认】），让「体积变化」这个可拍摄的形态差异自己说话（对比型产品创意，M-05）。
- **为什么可行**：T-base-04（有可证明的东西：收纳/折叠过程可拍，前提「可折叠」成立【待确认】）；T-base-02（反常识：「风扇能塞进笔袋」为待验证前提【待确认：可折叠且折叠后足够小】）。
- **开头钩子**：「一个能塞进笔袋的风扇？我一开始也不信。」（反常识 S-01-5；「能塞进笔袋」为待验证前提【待确认：可折叠且折叠后足够小】）
- **风险**：依赖「可折叠、折叠后体积小」成立【待确认】；对比型证明需真实可拍的过程画面（M-05），若实物不能折叠或体积无差则方向不成立。

## 方向 C：装备清单型——「学生党的续命装备」
- **一句话概念**：把该产品放进「学生党宿舍/桌面好物清单」，用「期末复习、晚自习、抢不到空调位」等共鸣场景做情绪入口，落脚到一个明确的收藏/加购动作。
- **为什么可行**：T-base-01（受众具体：期末复习、上自习的学生【推断】）；T-base-05（结尾留一个可执行动作：收藏/加购）。
- **开头钩子**：「期末周，我在图书馆永远抢不到靠窗的空调位。」（具体场景切入 E-base-01）
- **风险**：情绪向易软广化、缺可证明点（T-base-04 弱）；任何体验类断言须全程标【推断/待确认】，不得当事实（M-01、M-09）。

## 推荐：方向 B（对比证明型）
1. M-05 支持：对比型产品创意优先用可拍摄的过程/形态差异作证明，方向 B 的「体积差」（若「可折叠且折叠后足够小」成立【待确认】）正是可拍摄的形态差异。
2. 契合 T-base-04：在「已确认信息为零」的前提下，对比证明把不确定性变成「先拍出来验证」，比方向 A（免手持，靠「手是空的」实拍但更依赖口播解释【推断】）和方向 C（情绪类、缺证明）更不容易踩 M-01（把未确认属性当确定卖点）。
3. 「折叠」（产品名形容词，【待确认】）更适合用纯视觉过程直接证明【推断】；「便携」（体验，【推断】）与「颈挂」（形态，【待确认】）虽也能实拍，但更依赖口播解释，60 秒内证明成本更高。

## 方向 B 展开（老板 2026-11-18 选定）

### 1. 细化后的目标
给「学生党」看，60 秒内用一次「收纳前 vs 收纳后」的可拍摄对比，让 TA 记住这台产品【待确认：品类】的「体积变化」差异点【待确认：可折叠且折叠后体积可变】，并在结尾只做一个动作：**加购（加入购物车）**。主 CTA 已定为「加购」，全片结尾只喊这一个（S-01-7、M-02）。

### 2. 核心创意一句话
把「风扇能不能小到塞进书包/笔袋」这个反常识（【待确认：可折叠且折叠后足够小】），用一段折叠/收纳的过程实拍来证明，最后只留「加购」一个动作。

### 3. 结构（开场钩子 → 对比证明 → 落到加购）
- **开场钩子（约 0–3 秒）**：反常识开场「一个能塞进笔袋的风扇？我一开始也不信」（【待确认：可折叠且折叠后足够小】）。3 秒内出反常识（S-01-5、T-base-02）。
- **对比证明（约 3–50 秒）**：只证一个点——「体积变化」，用可拍摄的过程/形态差异：收纳前体积 → 折叠/收纳过程 → 收纳后塞进书包/笔袋（M-05 对比型；「折叠」「体积差」全程【待确认】）。不叠加「静音/续航/风力」等未确认卖点（M-01、T-base-04）。
- **落到加购（约 50–60 秒）**：把「体积差」这个唯一核心点收束（「体积差」本身【待确认：可折叠且折叠后体积可变】），结尾只喊一个动作「加购」（S-01-7、M-02、T-base-05），不并排「下单/收藏/关注」。

### 4. 选 B 的完整理由
- M-05：对比型产品创意优先以可拍摄的过程/形态差异作证明，B 的「体积差」（若「可折叠且折叠后足够小」成立【待确认】）正是可拍、可验的形态差异。
- T-base-04：B 的折叠/收纳过程可直接实拍证明（前提「可折叠」成立【待确认】）；方向 A 与 C 的可证明性弱于 B【推断】——A 的核心反差与 C 的情绪向都不像 B 这样自带一段可拍过程。
- T-base-02 + S-01-5：反常识钩子天然成立（「风扇能塞进笔袋」为待验证前提【待确认】），3 秒留人。
- M-01 抗性最强：证明型内容把「未确认」转化为「拍给你看」，用过程代替「喊卖点」，降低把未确认属性写成确定卖点的风险。
- P-base-02：60 秒只讲一个核心点（「体积差」，【待确认：可折叠且折叠后体积可变】），砍掉其他卖点，节奏优先。

### 5. 与「未确认属性」的对应
- 「折叠」「折叠后体积（可塞进书包/笔袋）」仍是【待确认】：全程只作「待验证的假设」进入内容，不作确定卖点；每个出现位置逐处标【待确认】。
- 「品类：风扇/能吹风」仍只来自产品名，【待确认】；本展开不额外引入「静音/续航/风力/价格」等未确认卖点（这些只留在「待确认项」，不进正文）。
- 核心反差与推荐理由都依赖「可折叠且折叠后足够小」成立；本节「风险与应对」已写明该依赖。

### 6. 需要的素材清单（当前全部「缺」）
- 折叠/收纳过程实拍（若实物支持折叠/收纳【待确认】：收纳前全景 → 折叠动作特写 → 收纳后）——缺
- 收纳前 vs 收纳后体积对比（若实物可折叠【待确认】；同一参照物，如书包/笔袋）——缺
- 「塞进书包/笔袋」过程实拍（若折叠后足够小【待确认】）——缺
- 学生党场景空镜（书包、课桌、宿舍桌面）——缺
- 产品外观/开合特写素材——缺
- 口播 / BGM / 字幕（script、edit 环节产出，此处仅登记需求）——缺
- 产品链接（用于「加购」落地）——缺（见「待确认项」第 2、3 条）

### 7. 风险与应对
- 风险 1：若实物不能折叠或折叠后体积无显著差，「体积差」证明不成立 → 应对：开拍前先让老板/asset 确认「可折叠且折叠后足够小」，否则改选 A/C 或回炉方向。
- 风险 2：全程依赖「可折叠」这一【待确认】属性，写成确定卖点会踩 M-01 → 应对：逐处条件式标【待确认】，正文不出现确定口吻的「折叠/能塞进书包」等未确认卖点。
- 风险 3：对比证明若拍不出过程、只剩口播说「能变小」，不可证明（T-base-04）→ 应对：以实拍过程为主体，口播只作旁白解释。
- 风险 4：素材「缺」导致无法实拍对比 → 应对：素材到位前不推进 script 的实拍分镜，先用占位描述。
- 风险 5：结尾 CTA 喊多个动作会违背 M-02/S-01-7 → 应对：全片结尾只喊「加购」一个。

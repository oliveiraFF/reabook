# 创意方案 — P009

## 目标（一句话）
给「想喝现磨【待确认】咖啡却常被设备、时间或空间劝退的人」【推断】看，让他看完愿意把「这台号称『便携』【待确认】的咖啡机到底能不能真出一杯【待确认】」当作一件值得跟进的待验证事项。

## 方向 A · 开箱首测（验证口径）
- 一句话概念：把「这台『便携咖啡机』【产品名；『便携』待确认】能否在受约束条件下自己完成『投料→出杯』【待确认：投料方式、出杯能力】全过程」当作主线，用「开箱→供电→投料→等待→出杯→清洗」的实拍逐步记录（其中供电【待确认】、投料【待确认】、出杯【待确认】、清洗【待确认】均为待核实的动作步骤），全程只讲「我观察到／我试了」，不下确定式结论。
- 为什么可行：
  - T-base-04：全片至少有一个可拍摄、可回看的过程——「从投料到出杯」【待确认：投料方式、出杯能力】的每一步都有画面，来源就是这条亲测过程本身。
  - T-base-02：观众对「咖啡机」的默认印象常是「大件、要插电、要等、难清洗」【推断】，而产品名里的「便携」【待确认】天然制造「我以为要一堆设备，其实可能不用」【推断】的反差，开头 3 秒就有冲突。
  - T-base-01：受众可先收窄到「想喝一杯、又不想为设备折腾的人」【推断】。
- 开头钩子：「『便携咖啡机』这五个字，到底是真『便携』【待确认】，还是广告词？我不看说明，只用一次——看它能不能在没有插座的桌子上【推断】真的自己出一杯【待确认】。」
- 风险（一句话）：核心反差依赖「便携」与「能独立出杯」【均待确认】；过程步骤（供电、投料方式、清洗）【均待确认】；若其中任一项不符（如不支持无线供电【待确认：供电方式】或出杯失败【待确认：出杯能力】），本方向反差落空。

## 方向 B · 场景冲突切入
- 一句话概念：用「想喝现磨【待确认：本机是否具备现磨能力】、却受制于时间／空间／设备」的生活冲突开场，把机器定位成「可能补上这个缺口」的对象，结尾只给一个可执行的判断方法，不直接种草。
- 为什么可行：
  - T-base-02：冲突是「想喝现磨 vs 当下没条件」【推断；现磨待确认】，开场先立冲突。
  - T-base-01：受众具体到「厨房之外的场景（工位／出差／通勤）里想快速喝一杯现磨的人」【推断；现磨待确认】。
  - T-base-03：一句话说得清——「没条件的时候，能不能快速【待确认：出杯速度】出一杯现磨【待确认】」。
  - T-base-05：结尾留下一个可执行的判断方法（观众看完能做什么），不写种草 CTA。
- 开头钩子：「你明明想喝现磨【待确认】，却因为『要一台大家伙、要插电、要洗一堆件』【推断】一次次算了——这台机器，是不是就是给这种时候准备的？」
- 风险（一句话）：核心价值同时锚在「现磨」与「便携」两项未确认能力上，二者【待确认】；若机器实为速溶／胶囊兼容【待确认】或并不便携【待确认】，冲突不成立。

## 方向 C · 对比验证（本机 vs 另一种喝法）
- 一句话概念：把机器和「另一种获得一杯咖啡的方式」（速溶／胶囊／手冲，三选一【待确认选谁】）并排，拍两者「从开始到喝到嘴」的步骤与等待差异——其中本机的出杯步骤、等待时长均【待确认】——用可拍摄的过程／形态差异作证明，不对口味下高下断言（口味【待确认】，故只做过程／形态对比）。
- 为什么可行：
  - T-base-04：至少一个可拍摄的过程对比——两边各要几步、要等多久、需要几件设备（本机侧的步骤、时长、设备件数均【待确认】），差异肉眼可看、可标来源。
  - T-base-03：一句话说得清——「同样是喝到一杯【待确认：出杯能力】，两条路到底差在哪」。
  - 依据 M-05：对比型产品创意优先用可拍摄的过程／形态差异作证明，不用未验证的口味断言（口味【待确认】）（本方向属对比型，在 M-05 适用范围内）。
- 开头钩子：「同样是『喝到一杯咖啡』这件事【待确认：出杯能力】，一条路要几步、另一条路要几步？我把两条路都走一遍给你看。」
- 风险（一句话）：需先确认「对比对象」与「本机能独立完成出杯」两项，均【待确认】；若两条路过程没有可观察差异，本方向失效。

## 推荐：方向 A（开箱首测·验证口径），理由
1. 本任务「确认项为零」，方向 A 通篇建立在不预设能力的「验证／观察／尝试」口径上（known-pitfalls #1 第③条要求的口径）；方向 C 虽同样用「观察／待确认」口径，但另需先定「对比对象【待确认】」。
2. 方向 A 的核心反差依赖「便携」与「能独立出杯」【均待确认】，过程步骤（供电、投料方式、清洗）【均待确认】；方向 B 另依赖「现磨【待确认】」，方向 C 另依赖「对比对象【待确认】」。三者依赖集不同，不据此断言 A 依赖最少。
3. 方向 A 与 T-base-04 贴合最紧：哪怕某项能力不成立，过程本身仍是可回看的内容；但作为「营销方案」，拍摄前须先确认「便携、出杯、供电、投料方式、清洗」这组依赖（均【待确认】），否则会滑向「打假／避坑」而非种草。

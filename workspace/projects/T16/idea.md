> 本方案由 idea 模块产出，仅用于「供老板从 3 个 60 秒短视频创意方向中选 1 个」，作为后续 script 展开脚本/分镜的输入；不含脚本、分镜、剪辑、拍摄、AI 视频生成。
> 判断规则 `T-base-NN` 出自 `feeds/thinking/base.md`（通用选题判断，**非咖啡行业专业证据**）；表达特征 `E-base-NN` 同源；风格规则 `S-01-NN` 出自 `feeds/style/S-01_通用短视频.md`。行业事实另附公开来源 URL。全文区分【事实】【推断】【建议】【待确认】【未查证】。
> 按「两步走」规则（老板 2026-11-15 决定）：老板选定方向前，本方案**不展开任何方向**（受众细化、渠道、节奏、转化、指标、预算均不写）；选定后将在本文件末尾追加「## 方向 X 展开」。

## 目标
一句话：给老板看，让老板从 3 个 60 秒短视频创意方向中选定 1 个，交给 script 展开成完整脚本与分镜。

## 方向 A / B / C

### 方向 A：反常识对比向 ——「方便咖啡＝速溶/难喝」
- **一句话概念**：用「你以为便携咖啡＝速溶/难喝，其实便携也能现磨」的反常识对比做钩子，主打出差/办公/通勤人群「随手现磨、不将就」，用「速溶 vs 现磨」的亲测对比撑满 60 秒。
- **为什么可行**：
  - 【规则】有反常识/冲突点——「方便＝难喝/速溶」是常见误解，可被对比实测戳破（T-base-02）；一句话能说清「方便也能现磨」（T-base-03）；「速溶 vs 现磨」亲测过程提供可证明内容（T-base-09）。
  - 【风格】开头 3 秒用反常识切入，符合 S-01-5；对比过程每 8–10 秒换一个信息点，符合 S-01-6；结尾只留一个行动引导，符合 S-01-7。
  - 【事实】2025 年中国便携咖啡机市场规模已达 128 亿元，年增速 42%，是增长最快的小家电品类之一。
  - 【事实】现磨咖啡将成为消费主流（中新网 2024-10-24，见文末依据 URL）；「把现磨门槛降低」正是便携咖啡机的叙事空间（【推断】）。
- **开头钩子（0–3 秒）**：「方便咖啡＝速溶，是咖啡圈最成功的一个误会。」
- **风险（一句话）**：把卖点押在「现磨口味」上，若实际出杯达不到「现磨」预期，反常识会反噬成负面口碑（口味【待确认】）。

### 方向 B：场景共鸣向 ——「工位/宿舍的一人咖啡角」
- **一句话概念**：用「工位/宿舍/出差酒店里，一个人也想喝一杯像样的现磨」的具体场景切入，把便携咖啡机讲成「不占地方、随时一人份」的随身咖啡角，主打独居青年/学生/职场人。
- **为什么可行**：
  - 【规则】受众具体——「独居/工位/宿舍的年轻职场人与学生」能说清「谁在什么场景喝」（T-base-01）；与大牌「家庭咖啡角」叙事做区隔、不重复（T-base-06）；结尾可留单一行动（T-base-05）。
  - 【风格】用具体场景而非概念开头，符合 E-base-01 与 S-01-5（具体场景切入）；竖屏 9:16 适合场景实拍，符合 S-01-2。
- **开头钩子（0–3 秒）**：工位一角实拍，画外音「在工位/宿舍也想喝现磨，但不想为它配一台大机器。」
- **风险（一句话）**：场景共鸣不足会「叫好不转化」；且工位/宿舍的供电、噪音、清洁限制需先验证，否则会被实测打脸（【待确认】）。

### 方向 C：过程实测向 ——「一杯现磨，到底麻不麻烦」
- **一句话概念**：一条 60 秒「过程实录/亲测」片，用「一杯现磨到底几步、麻不麻烦」的疑问做钩子，全程实录从拿出机器到出杯，主打「操作简单、不占地方、有过程可看」。
- **为什么可行**：
  - 【规则】有可证明的过程（开箱到出杯的亲测实录）与可给出处/过程的「几步」答案（T-base-04）；一句话能说清「不麻烦，几步就能喝上」（T-base-03）；结尾可给一个明确判断方法或行动（T-base-05）。
  - 【风格】用具体疑问/过程而非概念开头，符合 E-base-01；过程每 8–10 秒一个新信息点，符合 S-01-6；过程镜头以硬切为主，符合 S-01-9。
- **开头钩子（0–3 秒）**：手持实拍机器 + 画外音「一杯现磨，到底麻不麻烦？」
- **风险（一句话）**：纯过程片易滑向「说明书」，缺情绪记忆点；操作步骤、清洁难度、出杯时长等【待确认】参数若不理想会翻车。

## 推荐：方向 A，理由与取舍

- **推荐 A（反常识对比向）**：A 的冲突/反常识最强（T-base-02），最贴合 60 秒短视频「开头 3 秒留人」的硬规则（S-01-5）；「速溶 vs 现磨」对比天然提供可证明过程（T-base-04）与每 8–10 秒的画面变化（S-01-6），信息密度与节奏最容易在 60 秒内成立（【推断】）。相较 B 的「场景共鸣」（转化链路更长、依赖场景真实可用性）与 C 的「过程实测」（易像说明书、缺情绪记忆点），A 用一个强误解做钩子，起量与完播更可能占优（【推断】）。
- **为什么不是 B / C**：
  - 不选 B：情绪价值高、受众画像具体，但「一人咖啡角」依赖工位/宿舍的真实可用性（供电/噪音/清洁【待确认】），且共鸣向视频「看完有感觉但不下单」，转化链路更长。
  - 不选 C：过程可证明、钩子直接，但把卖点押在「操作简单/几步」上，一旦实际步骤、清洁、出杯时长（【待确认】）不理想会翻车；纯过程片也容易变成说明书，缺情绪记忆点。
- **A 的风险应对（供选定后展开）**：把「现磨」对比建立在真实亲测与口味事实之上；出杯时长等参数【待确认】前不写死数字；不做夸大、不做「保证」类承诺（S-01-11）。
- 以下**不展开任何方向**：按「两步走」规则，等老板选定方向后再追加展开。
